## Before you start

1. [Install the binaries](/docs/installation) and check that `mct-mcp-server --help` works.
2. Have the **absolute** path of the repository you want indexed. A relative `--root` resolves against whatever directory the client spawns the process from, which is rarely the repo.

## Rules that apply to every client

- At launch the server opens (or creates) the index in `<root>/.mct-index/` and runs an **incremental** reindex. The first start on a fresh checkout parses the whole repo; later starts only re-parse changed files.
- The server does not watch files. After a `git pull` or a branch switch, ask the agent to call `reindex`, or restart the client.
- Most clients only read their MCP config at startup: restart the client after adding or removing the server.

Config formats were checked against each client's official docs, and they still change often. If a client rejects a file, check its current docs first.
